# Architecture Decision Records (ADR)

Cada archivo registra una decisión técnica relevante: contexto, decisión tomada,
consecuencias y alternativas descartadas. No se editan para "cambiar de opinión";
si una decisión se revierte, se crea un ADR nuevo que la supera y se marca el
anterior como *Reemplazada por 00NN*.
